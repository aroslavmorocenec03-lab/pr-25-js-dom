# Практична робота №25

## Робота з DOM у JavaScript

Калькулятор суми двох чисел з історією операцій. Кнопка оновлює результат і додає новий пункт до списку, зберігаючи всі попередні обчислення.

## Запуск

1. Завантажте репозиторій через **Code → Download ZIP** і розпакуйте архів.
2. Відкрийте `index.html` у браузері.
3. Введіть два числа та натисніть **«Порахувати»**.
4. Змініть значення й повторіть обчислення. Усі записи залишаться в історії в порядку додавання.

Сервер, Node.js і встановлення пакетів не потрібні. Історія зберігається в DOM поточної сторінки й очищується після перезавантаження.

## Файли

| Файл | Призначення |
| --- | --- |
| `index.html` | Два текстові поля, знаки `+` та `=`, результат, кнопка й історія |
| `script.js` | Вибір DOM-елементів, перетворення значень, додавання та історія |
| `style.css` | Оформлення калькулятора та панелі історії, адаптація до вузьких екранів |
| `README.md` | Запуск, пояснення та відповіді на контрольні запитання |

## Відповідність завданню

- Обидва поля мають `type="text"` та ідентифікатори `value1`, `value2`.
- Між полями розташовано `+`, після другого поля — `=` та `<span id="result">`.
- Під полями розташована кнопка `id="calculate"` з підписом **«Порахувати»** та точним атрибутом `onclick="calculate()"`.
- Під кнопкою розміщена панель із заголовком **«Історія»** та списком `<ul id="history">`. Панель має рамку й внутрішні відступи.
- `script.js` підключено тегом `<script src="script.js"></script>` перед `</body>`.
- Посилання на поля, результат та історію отримуються через `document.getElementById()`.
- Функція `calculate()` зчитує `.value`, явно перетворює рядки через `Number()` та обчислює їхню суму.
- Результат записується через `resultElement.textContent`.
- Для кожного успішного обчислення `document.createElement("li")` створює новий пункт, `textContent` задає текст `a + b = сума`, а `appendChild()` додає його в кінець історії.

Додатково реалізовано перевірку порожніх і нечислових значень та переповнення. Помилковий ввід не додається до історії й не видаляє наявні записи. Enter у будь-якому з полів також запускає обчислення.

Для дробів використовуйте крапку. Результат відображає звичайне додавання JavaScript без додаткового округлення. Для деяких дробів, наприклад `0.1 + 0.2`, можливий результат `0.30000000000000004` через двійкове подання чисел типу `Number`.

## Приклади для перевірки

Виконайте наведені обчислення послідовно, не перезавантажуючи сторінку:

| Перше число | Друге число | Результат | Новий запис історії |
| ---: | ---: | ---: | --- |
| 2 | 3 | 5 | `2 + 3 = 5` |
| 10 | 5 | 15 | `10 + 5 = 15` |
| -4 | 7 | 3 | `-4 + 7 = 3` |
| 1.5 | 2.25 | 3.75 | `1.5 + 2.25 = 3.75` |
| 0 | 0 | 0 | `0 + 0 = 0` |

Після цих дій у списку мають залишитися всі п’ять записів. Потім введіть `abc` або залиште поле порожнім: має з’явитися повідомлення про помилку, а історія повинна залишитися незмінною.

## Відповіді на контрольні запитання

1. **Який метод отримує елемент за `id` і що він повертає?** `document.getElementById("id")` повертає DOM-елемент із відповідним ідентифікатором або `null`, якщо елемента немає. У коректній розмітці `id` унікальні, тому для вибору конкретного елемента пошук за CSS-селектором не потрібний.
2. **Чому `.value` потрібно перетворювати через `Number()`?** Значення текстового поля є рядком. Явне перетворення дає число для арифметичного додавання.
3. **Що поверне `"2" + "3"` без перетворення?** Рядок `"23"`, оскільки `+` виконує конкатенацію рядків. Після `Number("2") + Number("3")` результат — число 5.
4. **Як `onclick` пов’язує кнопку з функцією?** Браузер виконує код атрибута під час натискання. У нашій розмітці `onclick="calculate()"` викликає однойменну функцію зі звичайного зовнішнього скрипта. Вона має бути доступною в глобальній області видимості, тому тут не використано модуль чи замикання навколо цієї функції.
5. **Чим `onclick` відрізняється від `addEventListener()`?** Атрибут задає обробник у HTML. `addEventListener("click", handler)` підписує його в JavaScript і дозволяє додати кілька незалежних обробників. У роботі кнопка використовує саме атрибут, як зазначено в завданні.
6. **Чим відрізняється `textContent` від `createElement()` та `appendChild()`?** Присвоєння `textContent` замінює текстовий вміст наявного елемента, видаляючи його попередні дочірні вузли. `createElement()` створює окремий новий вузол, а `appendChild()` додає його до контейнера, не видаляючи попередніх дітей.
7. **Чому для результату достатньо одного елемента, а для історії потрібні нові?** Результат має показувати лише останню суму, тому його текст замінюється. Історія має зберігати кожну операцію, отже для неї додаються окремі `li`.
8. **Що буде, якщо щоразу змінювати `textContent` контейнера історії?** Попередній вміст контейнера разом із пунктами списку буде замінено. Залишиться тільки останній запис, тому історія перестане накопичуватися.
